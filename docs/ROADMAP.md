# Engineering roadmap

1. Foundation: local Compose, API gateway, synthetic engine and React shell — **prototype delivered**.
2. Identity: authentication, per-organization RBAC, audit logging, authorization tests — **not implemented**.
3. Digital twin: PostgreSQL domain schema, CRUD, import/export, immutable snapshots — **not implemented**.
4. Reasoning: expanded rule semantics, uncertainty, bounded state exploration, test corpus — **partially implemented**.
5. Simulations: async job queue, immutable runs, comparison UI — **partially implemented**.
6. Defense optimization: OR-Tools solver, constraints, solver proof and verification — **prototype uses bounded exhaustive search**.
7. Ghost Lab: strictly isolated, permission-limited synthetic environments — **not implemented**.
8. AI Investigator: optional local Ollama, evidence-grounded summaries, untrusted content isolation — **not implemented**.
9. Production readiness: report generation, public/private separation, rate limits, comprehensive tests, CI/CD, hardening — **not implemented**.

Do not describe prototype UI or modeled attack paths as operational threat detection.
