# Official brand implementation

- Concept: Cinematic Cybersecurity / Ghost Minimalist.
- Palette: Ghost Black #050B13; Midnight Navy #0B1828; Spectral Cyan #00D5F5; Phantom Gold #E6B65A; Ice White #F2F7FC; Slate Blue #93A8BA.
- Typography: Montserrat (headings), Inter (interface), JetBrains Mono (technical data).
- Mark: original editable SVG hooded specter with dark face and cyan eyes.
- Assets: `apps/web/public/theghost-mark.svg`, `favicon.svg`, `favicon.ico`, `apple-touch-icon.png`, `theghost-horizontal.svg`.
- Both public landing and private demo workspace share the same logo component.
- The original concept image was a visual reference; this SVG is a clean vector interpretation, not a pixel-perfect tracing.
- All demo data must remain explicitly synthetic; planned modules must be labeled as planned.
